# 纸纹与边缘晕染背景设计

## 背景

逍遥哥的知识库已经采用 Astro Cactus 的窄栏、留白和明暗主题体系。新增背景需要提供可感知的纸张质感，但不能把阅读区域变成装饰性画布，也不能降低正文、搜索弹窗或代码块的可读性。

用户在可视化对比中选择了第 3 种方案：轻微可见的纸纹与边缘晕染。

## 目标

- 为首页、文章、笔记、标签、关于和 404 页面提供一致的全站背景。
- 浅色模式呈现暖白纸张，深色模式呈现低对比炭灰纸张。
- 中央阅读区域保持清晰，颜色从中心向视口边缘轻微加深。
- 不增加图片请求、动画或布局变化。
- 保留 Astro Cactus 的现有正文宽度、颜色体系和交互行为。

## 非目标

- 不增加背景选择器或用户自定义强度设置。
- 不添加摄影图、插画、粒子动画或滚动视差。
- 不改变文章、笔记、搜索和导航的组件结构。
- 不调整现有字体、正文颜色或卡片样式。

## 视觉设计

背景由两层 CSS 图案组成：

1. 径向渐变以阅读区域上部为视觉中心，中间透明，向四周逐步叠加低透明度中性色，形成书页边缘晕染。
2. 低透明度重复线性渐变以较大间隔生成不规则纸纤维感，避免出现明显条纹或规则网格。

纹理强度保持“轻微可见”：正常阅读距离能感到纸张层次，但正文仍是第一视觉焦点。背景不使用独立卡片承载正文，也不在内容区域增加不透明面板。

## 技术设计

- 在 `src/styles/global.css` 的主题层新增纸张背景颜色变量。
- 将背景绘制在 `html` 根元素上，使纹理覆盖整个视口，而不是只覆盖当前 `body` 的 `max-w-3xl` 内容宽度。
- 从 `src/layouts/Base.astro` 的 `body` 移除实色背景工具类，使根元素背景可见；正文颜色和布局类保持不变。
- 背景图层使用纯 CSS `radial-gradient` 与 `repeating-linear-gradient`，不新增资源文件或网络请求。
- 使用主题选择器覆盖深色模式的晕染与纤维颜色。主题切换仍由现有 `ThemeProvider` 管理，不增加脚本。
- 根元素保留 `background-color: var(--color-global-bg)`。若浏览器不支持渐变，自动退化为当前纯色背景。
- 不使用动画或视差；背景固定在页面坐标中，滚动长文时不产生视觉漂移。

## 明暗主题

浅色模式：

- 基色沿用现有接近白色的 `--color-global-bg`。
- 晕染使用暖灰棕中性色，透明度控制在不影响正文对比度的范围。
- 纸纤维使用更低透明度的灰棕色。

深色模式：

- 基色沿用现有炭灰色 `--color-global-bg`。
- 晕染改用更深的中性黑，避免出现彩色光晕。
- 纸纤维使用低透明度浅灰，在普通显示器上仅形成细微层次。

## 可访问性与性能

- 背景没有语义信息，不使用额外 DOM 或辅助技术标签。
- 不改变文本与背景的现有主题颜色变量，正文对比度不会因新纹理被主动降低。
- 不引入图片、字体、JavaScript 或第三方依赖。
- CSS 图案为静态绘制，不产生持续动画或定时器。
- 在不支持渐变的浏览器中保留纯色背景，页面内容仍完整可用。

## 验收标准

- 1440 x 1000 桌面视口中，背景覆盖整个视口，左右区域没有纯色断层。
- 390 x 844 手机视口中，没有水平滚动、布局位移或文字遮挡。
- 浅色和深色主题下，纸纹与边缘晕染均可见但不抢正文焦点。
- 首页、文章页、笔记页、标签页、关于页和 404 页使用同一背景。
- 搜索弹窗、导航、代码块、链接和主题切换行为保持正常。
- 浏览器控制台无新增错误或警告。
- `pnpm test`、`pnpm check:content`、`pnpm check` 和 `pnpm build` 全部通过。

## 发布方式

背景通过现有 Cloudflare Pages 静态发布流程上线。构建成功后使用 Wrangler 发布 `dist/`，再验证正式地址的首页、文章、搜索、明暗主题和移动端截图。
