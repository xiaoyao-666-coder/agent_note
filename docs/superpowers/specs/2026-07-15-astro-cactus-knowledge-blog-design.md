# 逍遥哥的知识库：设计说明

## 目标

创建一个公开、中文优先、适合长期积累的知识型个人博客。站点以 Markdown/MDX 为主要内容格式，既能发布完整文章，也能整理短笔记、GitHub 项目记录和命令备忘，并通过 Cloudflare Pages 对外提供快速、稳定的访问。

首版成功标准：

- 在桌面和手机上均可正常阅读和导航。
- 文章、笔记、标签和全文搜索均可工作。
- 中文搜索可以命中标题与正文。
- RSS、站点地图、草稿过滤和代码高亮可用。
- 生产构建通过并发布到可访问的 `pages.dev` 地址。
- 不导入任何未经明确选择的旧仓库内容或敏感信息。

## 技术方案

- 基础模板：Astro Cactus。
- 内容框架：Astro Content Collections。
- 样式：保留 Cactus 的简洁、文本优先布局，完成中文化和轻量品牌定制。
- 搜索：Pagefind 静态全文索引。
- 部署：Cloudflare Pages，静态输出目录为 `dist`。
- 内容源：新建、独立的博客仓库；站点源码只包含可公开内容。

选择 Cactus 的原因是它原生区分文章与笔记，并已提供标签、搜索、RSS、SEO、草稿、站点地图和代码展示能力。首版不引入数据库、CMS 或服务端渲染，降低维护成本和公开内容边界风险。

## 信息架构

站点名称暂定为“逍遥哥的知识库”。顶部导航保持精简：

- 首页
- 文章
- 笔记
- 标签
- 搜索
- 关于

内容分为三个维度：

- 文章：完整教程、研究总结、项目复盘等长内容。
- 笔记：GitHub 笔记、命令、片段和短记录。
- 标签：跨文章和笔记的主题入口，例如 Cloudflare、GitHub、AI、实验记录。

首版首页展示简短站点介绍、最新文章、最近笔记和常用标签，不使用营销式大标题或装饰性卡片堆叠。

## 视觉与交互

- 使用 Cactus 已有的排版和深色/浅色主题作为设计基准。
- 中文正文优先保证字号、行高和代码块可读性。
- 强调色克制使用，页面以中性色为主，避免单一色调铺满界面。
- 搜索、主题切换和移动端导航都必须具有明确的键盘焦点和可访问名称。
- 动效仅保留轻量过渡，并尊重系统的减少动态效果设置。

由于用户已经明确选择 Astro Cactus，模板本身即为已接受的视觉基准，不另外生成与模板风格冲突的概念稿。

## GitHub 内容流程

首版先建立安全的内容目录和示例，不自动抓取现有仓库。

后续同步遵循以下规则：

1. 用户明确指定允许公开的仓库与目录。
2. 同步流程只复制白名单中的 Markdown 和配套公开图片。
3. 构建前检查常见 token、密钥、私有地址和草稿标记。
4. 同步后的内容进入 Astro 内容校验；元数据不完整时构建失败，而不是静默发布。
5. GitHub 推送触发 Cloudflare 自动构建；分支或 PR 使用预览地址检查后再合并。

首版不会把其他仓库的历史、Issues、私有文件或环境变量复制到公开站点。

## 发布范围

- 首次发布使用 Cloudflare 提供的 `pages.dev` 域名。
- 如果本机已有 Cloudflare 登录状态，直接创建 Pages 项目并部署；否则通过 Wrangler 的官方 OAuth 登录。
- GitHub 自动部署在安全的独立博客仓库可创建并授权时接入。
- 自定义域名需要用户提供具体域名后另行绑定。
- Cloudflare Web Analytics 在账号与项目权限允许时启用。
- 评论功能保留接口，但只有在公开 GitHub 仓库启用 Discussions 后才配置 Giscus。

## 验证

- 运行依赖安装、类型检查和生产构建。
- 检查首页、文章、笔记、标签、搜索、RSS、站点地图和 404 页面。
- 使用真实浏览器验证桌面与手机布局、深浅主题和导航。
- 检查中文长标题、代码块、图片和链接不会溢出或重叠。
- 构建后验证 Pagefind 索引包含中文示例内容。
- 部署后访问生产地址，并确认 HTTPS 和主要页面返回正常。

## 明确不包含

- 未指定的既有 GitHub 笔记自动公开。
- 登录、付费订阅、后台 CMS、数据库和动态用户系统。
- 未提供域名时的自定义域名绑定。
- 为了展示而添加的虚假文章、统计数据或不可用控件。
